# 도깨비 노선도 (웹 시제품 v1.0 · PWA)

지하철 노선도 위에서 원정대 넷을 첫차부터 막차까지 실어 나르는 점수 쌓기 로그라이크. 거꾸로 달려오는 도깨비 열차는 봉쇄 테이프로 막는다. (이전 이름 「말판 원정대」 — 윷·주사위·체스판은 정리했다)

기획은 [DESIGN.md](DESIGN.md).

```bash
cd yut
python tools/save-server.py . 7373   # 캐시 없는 개발 서버 → http://localhost:7373
npm test                       # 규칙 테스트 (node --test)
npm run sim -- 2000            # 밸런스 시뮬레이터: 정책별 요일 통과율·완주율
node tools/sim.mjs 2000 1 daily  # 오늘의 노선만
```

- 메인에서 **5일 운행**(월~금, 날마다 새 노선도) 또는 **오늘의 노선**(하루짜리, 날짜로 시드를 정해 그날은 누구나 같은 노선도)을 고른다
- 주소에 `?seed=5` 를 붙이면 같은 원정이 다시 나온다. `?day=3` 은 수요일(첫 보스 날)부터, `?day=5` 는 금요일부터(테스트용)
- **운행 시계**: 하루는 06:00 첫차에 시작해 24:00 막차에 끝난다. 한 번 달릴 때마다 출발 45분 + 역마다 15분(급행은 역마다 8분)이 흐르고, 갈 길이 없으면 30분 기다린다. 막차 전에 목표 점수를 넘기면 그날 운행 완료, 못 넘기면 원정이 끝난다
  - 시간대: 07~09시·18~20시 러시아워(이동 칩 +50%, 손님이 많다) · 22시 심야(안개가 짙다) · 23시 막차(골인 배수 +3)
  - 파란 도깨비 열차가 출발역까지 가면 운행이 30분 지연된다. 남긴 시간은 정산 토큰과 승점으로 돌아온다
- **봉쇄 테이프**: 하루 2장. 던지기 전에 역 하나를 골라 치면 3시간 동안 도깨비 열차가 그 역을 지나가지도 서지도 못한다 · 단추 또는 B
- 던지기: "열차 출발"을 꾹 누르면 손맛 게이지가 오르내리고, 떼는 순간 출발한다. 초록 굿(두 번 굴려 좋은 쪽), 한가운데 퍼펙트(세 번 중 가장 좋은 쪽), 끝 삐끗(두 번 중 나쁜 쪽). 톡 누르면 그냥 출발 · Space/Enter · R 다시 굴리기
- 노선도: 날마다 새로 짜이는 가로로 긴 노선도(38~51역). 1호선(본선) 30역이 네 줄 S 자로 지나고 우회 지선·연결선 5~9갈래가 갈라진다. 갈래마다 2~5호선 — 급행선(칩)·공원선(칩·토큰)·상업선(토큰)·축제선(배수)
  - 깃발: 멈춘 역에 꽂힌다. 한 호선 역에 모두 꽂으면 호선 완성(점수 +80·토큰 +2, 특화 효과 2배, 도깨비 통행료). 도깨비 열차가 밟으면 깃발을 뺏긴다
  - 손님: 역에 나타난 손님을 태워 원하는 호선 역에 내려 주면 칩 +30·토큰 +1
  - 도깨비 열차는 종점에서 거꾸로 달려오고, 머리 위에 다음 갈림길에서 탈 호선이 보인다
  - 수요일은 도깨비 차장(서행 운전·합승 금지·도깨비 급행·요금 반값 중 하나), 금요일은 늘 호선 하나 운행 중지
- 원정대(지하철 직원): 기관사 호랑이(돌파 · 스킬 경적) · 역무원 토끼(안전 요원 · 추가 운행) · 안내원 앵무새(안내방송 · 승객 호출) · 보안관 판다(만원 열차 · 스크린도어). 스킬은 하루 한 번, 노선 위에 나와 있을 때 출발 전에. 쓰면 컷인 연출
- 역 매점: 하루를 마치면 정기권(점수 효과, 왼쪽부터 계산)·역 개조(내일 노선도의 빈 역)·노선 연장권(내일 갈래 +1)을 토큰으로 산다
- 돌발 사건: 하루 2번, 위쪽 예고("사건 11:00")의 시각에 터진다 — 분실물 대방출·황금 역·도깨비 열차 회차·역 버스킹·연장 운행·토큰 줍기(좋은 일), 도깨비 폭주(나쁜 일)
- 랭킹(기기 안): 하루를 목표대로 마칠 때마다 승점(남은 운행 1시간마다 +2), 원정이 끝나면 기록. 칭호는 수습 역무원 → 정식 역무원 → 노련한 기관사 → 역장 → 전설의 노선 지기
- 캐릭터 도감: 메인의 "캐릭터 도감" 단추나 원정대 카드. 동작 보기, 능력·스킬 설명, 스킬 연출 미리 보기, 도깨비 열차와 도깨비 차장 규칙
- 화면 보는 법: 점수판은 줄마다 이름표(점수 · 만족도 · 시각)가 붙어 있고, 줄이나 위쪽 알약(사건·차장·토큰)·호선 깃발·**?** 단추를 누르면 그 항목 설명이 열린다. 처음 운행할 때 한 번 자동으로 뜬다
- 화면: 폰(세로)은 390×844 틀(위 점수·운행 시계 / 가운데 노선도 / 아래 조작판), PC(가로가 긴 창)는 노선도가 왼쪽을 가득 채우고 점수·조작판이 오른쪽 패널로 간다

## 앱(PWA)으로 설치

**바로 하기: https://alekf9099.github.io/malpan/** (공개 저장소 [alekf9099/malpan](https://github.com/alekf9099/malpan) 의 GitHub Pages)

`manifest.webmanifest` · `sw.js` · `assets/icons/` 가 들어 있어 HTTPS 주소에 올리면 홈 화면에 설치할 수 있다.

배포 갱신 — 작업 저장소의 `yut/` 폴더만 떼어 공개 저장소로 보낸다(몇 분 뒤 Pages 에 반영):

```bash
git subtree split --prefix=yut -b malpan-pages
git push https://github.com/alekf9099/malpan.git malpan-pages:main
git branch -D malpan-pages
```

새 버전을 올릴 때 `sw.js` 의 `CACHE` 이름(예: `malpan-v10` → `malpan-v11`)을 바꾸면 설치된 앱의 옛 캐시가 지워진다.

- 안드로이드 크롬: 메뉴 → **앱 설치**(또는 홈 화면에 추가)
- 아이폰 사파리: 공유 → **홈 화면에 추가**
- PC 크롬·엣지: 주소창 오른쪽 설치 아이콘

한 번 끝까지 열어 두면 오프라인에서도 열린다(네트워크 우선, 끊기면 캐시). 개발 서버(localhost)에서는 캐시가 수정 확인을 방해하지 않도록 서비스 워커를 등록하지 않는다. 아이콘은 `python tools/make-icons.py` 로 다시 만든다.

## 구조

| 경로 | 내용 |
|---|---|
| `src/core/` | 규칙 전부. DOM 을 모르고 이벤트 목록을 돌려준다 — `round` 운행 시계·이동·잡기·함께 타기·점수·봉쇄·도깨비 AI · `run` 5일 운행·오늘의 노선·정산·매점 · `items` 정기권·역 개조·도깨비 차장 · `board` 출발/골인 상수 |
| `src/core/boards/metro.js` | `makeMetro(seed, { extra, closed })` 가 노선도를 짠다. `options` 둘 수 있는 수 · `ahead` 안개 · `nextFork` 행선지 · `lineAt` 호선 · `blocked` 운행 중지 |
| `src/core/heroes.js` | 원정대 캐릭터(직업)·고유 능력(훅)·스킬(`active`). 스킬 효과는 `round.js` 의 `useSkill` |
| `src/core/events.js` | 돌발 사건 목록과 하루 계획(몇 시에 무엇) |
| `src/core/ranking.js` | 승점 계산과 칭호. 저장은 `src/ui/records.js`(localStorage) |
| `src/ui/` | 그리기만. `board-view` 아이소메트릭 노선도 · `camera` 따라가기·맞추기·끌기 · `roller3d` 3D 열차 주사위(`roller` 는 2D 대체) · `anim` 점프·찌그러짐·날려 보내기 · `fx` 먼지·폭죽·스티커 · `art` 캐릭터 스프라이트·정기권·토큰·테이프 그림 · `sound` Web Audio 합성 · `app` 이벤트를 차례로 연출 |
| `tests/` | 노선도 생성·갈림길·안개, 운행 시계·시간대·막차, 봉쇄, 잡기·함께 타기·골인, 점수, 정기권, 보스, 정산·매점, 시드 재현, 끝까지 가는지 |
| `tools/sim.mjs` | 무작위 · 탐욕 · 매점까지 쓰는 · 위험을 피하며 봉쇄까지 쓰는 정책으로 N 원정을 돌린다 |
