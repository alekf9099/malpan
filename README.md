# 도깨비 노선도 (웹 시제품 v2.1 · PWA)

서울 지하철 노선도 위에서 원정대 넷을 첫차부터 막차까지 출발역 → 종착역으로 보내는 점수 쌓기 로그라이크. 거꾸로 달려오는 도깨비 열차는 봉쇄 테이프로 막고, 역마다 터지는 화재·신호 장애·인파·버스킹을 피하거나 이용한다. (이전 이름 「말판 원정대」)

기획은 [DESIGN.md](DESIGN.md).

```bash
cd yut
python tools/save-server.py . 7373   # 캐시 없는 개발 서버 → http://localhost:7373
npm test                       # 규칙 테스트 (node --test)
npm run sim -- 2000            # 밸런스 시뮬레이터: 정책별 요일 통과율·완주율
node tools/sim.mjs 2000 1 daily  # 오늘의 노선만
```

- 메인에서 **5일 운행**(월~금, 날마다 다른 구간) 또는 **오늘의 노선**(하루짜리, 날짜로 시드를 정해 그날은 누구나 같은 구간)을 고른다
- 주소에 `?seed=5` 를 붙이면 같은 원정이 다시 나온다. `?day=3` 은 수요일(첫 보스 날)부터, `?day=5` 는 금요일부터(테스트용)
- **서울 노선도**: 1~9호선 주요 역 86곳을 간추린 실제 노선도(역 이름·잇는 순서는 실제를 따르고 사이 역 몇 개를 건너뛰었다, 2호선은 순환선). 위에서 내려다본 평면 지도로 크게 그리고, 카메라가 말을 따라간다. "서울 전체" 단추로 지도 전체를 본다
  - **오늘 구간**: 날마다 출발역 → 종착역이 정해진다(예: 왕십리 → 가산디지털단지, 홍대입구 → 잠실). 가장 짧은 길보다 두 역까지 더 돌아가는 길이 모두 열리고(진한 선), 나머지 지도는 옅게 남는다. 되돌아가는 길은 없다
  - 환승역(큰 동그라미)에서 다른 호선으로 갈아탄다. 환승역에 서면 칩 +8
  - 도깨비 열차는 종착역에서 거꾸로 달려오고, 머리 위에 다음 갈림길에서 탈 호선이 보인다
  - 수요일은 도깨비 차장(서행 운전·합승 금지·도깨비 급행·요금 반값 중 하나), 금요일은 늘 호선 하나 운행 중지(끊어도 구간이 이어지는 호선만)
- **역 인수 · 통행료**(부루마불식): 내 말이 멈춘 역은 출발 전에 **점수로 인수**한다(일반역 50 · 환승역 100 · 세 호선 환승역 160, 점수가 모자라면 묻지 않는다). 도깨비 열차가 내 역에 서면 **통행료**(값의 4분의 1 × 연결 배수)가 내 점수로 들어온다
  - 산 역은 **기기에 저장되어 계속 내 것**이다 — 원정이 끝나도, 다음 원정·오늘의 노선에서도. 메인의 "내 노선망"·랭킹 화면에서 가진 역·연결을 보고, 초기화할 수 있다
  - **연결 배수**: 같은 호선에서 이어서 산 역이 많을수록 배수가 오른다 — 통행료 2역 ×2 · 3역 ×3 · 4역 이상 ×4, 내 말이 연결된 내 역에 서면 점수 배수 +1(2역)·+2(3역 이상). 이어진 구간엔 노선도에 금빛 띠가 흐른다. 인파 몰린 내 역은 통행료 2배, 불난 내 역은 못 받는다
  - 노선망이 클수록 승객이 늘어 그날 목표가 오른다(내 역 1곳마다 +0.5%, 최대 +35%) — 그래도 큰 노선망이 훨씬 유리하다
  - 내 역에 내 말이 서면 칩 +10. 보스 날(수·금)엔 도깨비 차장이 구간의 역 두 곳을 **도깨비 역**(보랏빛 깃발)으로 — 내 말이 서면 내가 통행료를 낸다
  - 효과: 인수하면 점수판에서 토큰이 날아가 역에 꽂히고 금빛 깃발이 떨어진다(금전등록기 소리·고리·폭죽). 통행료는 깃발이 펄럭이며 토큰이 점수판으로 쏟아지고(연결 배수만큼 많이), 역이 이어지면 "2호선 3역 연결!" 호선 색 카드가 떨어진다
  - 역 이름·깃발 통행료 표: 역 사이가 가까운 곳에서도 겹치지 않도록 지도 간격을 넓혔고(1단위 150px), 옆 역 이름에 닿는 깃발 표는 왼쪽·위로 옮겼다
- **역 사건**: 도깨비 차례가 끝날 때마다 확률로 역 하나에 일이 터진다. 위에 **속보** 띠가 지나가고 카메라가 그 역으로 가서, 역에 움직이는 표시가 붙는다
  - 화재(불꽃·연기·불티): 2시간 동안 아무도 지나가지도 서지도 못한다. 출발역 → 종착역 길을 끊는 역에는 나지 않는다
  - 신호 장애(퍼지는 노란 고리·도는 시곗바늘): 지나가거나 서면 30분 더 걸린다
  - 인파 몰림(들썩이는 사람들): 서면 칩 +40 · 역 버스킹(떠오르는 음표): 서면 배수 +2. 둘은 한 번 누리면 사라진다
- **운행 시계**: 하루는 06:00 첫차에 시작해 24:00 막차에 끝난다. 한 번 달릴 때마다 출발 45분 + 역마다 15분(급행은 역마다 8분)이 흐르고, 갈 길이 없으면 30분 기다린다. 막차 전에 목표 점수를 넘기면 그날 운행 완료, 못 넘기면 원정이 끝난다
  - 시간대: 07~09시·18~20시 러시아워(이동 칩 +50%, 인파가 잦다) · 22시 심야 할증(이동 칩 +25%) · 23시 막차(골인 배수 +3)
  - 파란 도깨비 열차가 출발역까지 가면 운행이 30분 지연된다. 남긴 시간은 정산 토큰과 승점으로 돌아온다
- **봉쇄 테이프**: 하루 2장. 던지기 전에 역 하나를 골라 치면 3시간 동안 도깨비 열차가 그 역을 지나가지도 서지도 못한다 · 단추 또는 B
- 던지기: "열차 출발"을 꾹 누르면 손맛 게이지가 오르내리고, 떼는 순간 출발한다. 초록 굿(두 번 굴려 좋은 쪽), 한가운데 퍼펙트(세 번 중 가장 좋은 쪽), 끝 삐끗(두 번 중 나쁜 쪽). 톡 누르면 그냥 출발 · Space/Enter · R 다시 굴리기
- 원정대(지하철 직원): 기관사 호랑이(돌파 · 스킬 경적) · 역무원 토끼(안전 요원 · 추가 운행) · 안내원 앵무새(안내방송 — 인파 역에서 칩 더 · 스킬 승객 호출로 인파 두 곳) · 보안관 판다(만원 열차 · 스크린도어). 스킬은 하루 한 번, 노선 위에 나와 있을 때 출발 전에. 쓰면 컷인 연출
- 역 매점: 하루를 마치면 정기권(점수 효과, 왼쪽부터 계산 — 임대 계약서 통행료 +50%, 등기 권리증 역 값 25% 할인 포함 15종)·노선 연장권(내일 구간이 넓어져 돌아가는 길이 늘어난다)을 토큰으로 산다. 매점에서 내일 구간이 보인다
- 돌발 사건: 하루 2번, 위쪽 예고("사건 11:00")의 시각에 구간 전체에 터진다 — 역세권 세일(역 값 반값)·역세권 호재(통행료 2배)·도깨비 열차 회차·역 축제(버스킹 세 곳)·연장 운행·토큰 줍기(좋은 일), 도깨비 폭주(나쁜 일)
- 랭킹(기기 안): 하루를 목표대로 마칠 때마다 승점(남은 운행 1시간마다 +2), 원정이 끝나면 기록. 칭호는 수습 역무원 → 정식 역무원 → 노련한 기관사 → 역장 → 전설의 노선 지기
- 캐릭터 도감: 메인의 "캐릭터 도감" 단추나 원정대 카드. 동작 보기, 능력·스킬 설명, 스킬 연출 미리 보기, 도깨비 열차와 도깨비 차장 규칙
- 화면 보는 법: 점수판은 두 줄(점수 · 시각)에 이름표가 붙어 있고, 줄이나 위쪽 알약(사건·차장·토큰)·오늘 구간 띠·**?** 단추를 누르면 그 항목 설명이 열린다. 처음 운행할 때 한 번 자동으로 뜬다
- 화면: 폰(세로)은 390×844 틀(위 점수·시각 / 가운데 노선도 / 아래 조작판), PC(가로가 긴 창)는 노선도가 왼쪽을 가득 채우고 점수·조작판이 오른쪽 패널로 간다

## 앱(PWA)으로 설치

**바로 하기: https://alekf9099.github.io/malpan/** (공개 저장소 [alekf9099/malpan](https://github.com/alekf9099/malpan) 의 GitHub Pages)

`manifest.webmanifest` · `sw.js` · `assets/icons/` 가 들어 있어 HTTPS 주소에 올리면 홈 화면에 설치할 수 있다.

배포 갱신 — 작업 저장소의 `yut/` 폴더만 떼어 공개 저장소로 보낸다(몇 분 뒤 Pages 에 반영):

```bash
git subtree split --prefix=yut -b malpan-pages
git push https://github.com/alekf9099/malpan.git malpan-pages:main
git branch -D malpan-pages
```

새 버전을 올릴 때 `sw.js` 의 `CACHE` 이름(예: `malpan-v11` → `malpan-v12`)을 바꾸면 설치된 앱의 옛 캐시가 지워진다.

- 안드로이드 크롬: 메뉴 → **앱 설치**(또는 홈 화면에 추가)
- 아이폰 사파리: 공유 → **홈 화면에 추가**
- PC 크롬·엣지: 주소창 오른쪽 설치 아이콘

한 번 끝까지 열어 두면 오프라인에서도 열린다(네트워크 우선, 끊기면 캐시). 개발 서버(localhost)에서는 캐시가 수정 확인을 방해하지 않도록 서비스 워커를 등록하지 않는다. 아이콘은 `python tools/make-icons.py` 로 다시 만든다.

## 현재 밸런스 (v2.1, 역 인수·연결 배수·역 사건·돌발 사건·스킬 포함, 손맛 게이지는 쓰지 않은 기준)

시뮬레이터는 막차까지 6시간 넘게 남았고 점수가 값을 넘으면 멈춘 역을 산다.

5일 운행 — 기본 목표 월 1300 · 화 2000 · 수 2600(차장) · 목 3700 · 금 4800(운행 중지), 노선망이 크면 최대 +35%

처음 시작(산 역 없음, 500원정)

| 정책 | 월 | 화 | 수 | 목 | 금 | 완주 | 하루 이동 횟수 |
|---|---|---|---|---|---|---|---|
| 무작위 | 36.0% | 13.3% | 8.3% | 0% | — | 0% | 11.7 |
| 탐욕(매점 안 씀) | 86.6% | 55.7% | 10.4% | 8.0% | 0% | 0% | 10.0~11.5 |
| 탐욕 + 매점 | 86.6% | 79.0% | 49.7% | 63.5% | 46.3% | 10.0% | 10.3~11.2 |
| 위험 고려 + 매점 + 봉쇄 | 92.4% | 83.1% | 60.9% | 70.5% | 49.1% | 16.2% | 9.5~11.0 |

산 역을 다음 원정에 넘기며 300원정을 이어서 했을 때(`node tools/sim.mjs 300 1 carry`) — 노선망이 자라 쉬워진다

| 정책 | 완주(전체) | 마지막 75원정 완주 | 끝에 가진 역 |
|---|---|---|---|
| 탐욕 + 매점 | 34.3% | 40.0% | 68곳 / 86 |
| 위험 고려 + 매점 + 봉쇄 | 44.0% | 42.7% | 67곳 / 86 |

오늘의 노선(목표 1650, 도깨비 열차 3대, 정기권 없이, 산 역 없이, 400원정) — 탐욕 63.0% · 위험 고려 72.5%

연결 배수를 그대로 쓰면(통행료 값의 절반 × 최대 4, 내 역 배수 +3) 노선망이 커진 뒤 완주율이 96% 까지 올라 하루가 4~5번 만에 끝났다. 그래서 통행료 기본값을 값의 4분의 1로, 내 말이 받는 배수를 +2 까지로 낮추고, 노선망 크기만큼 목표를 올렸다. 어느 역을 이어서 살지·도깨비를 내 역으로 몰지를 생각하는 사람이면 이보다 높아야 한다 — 플레이테스트로 확인할 부분.
